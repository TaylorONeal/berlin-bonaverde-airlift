# Security

Berlin Airlift has no server, no accounts and no network access, so the attack surface is small: the app, the NFC cards it writes, and the machine that reads them.

If you find a problem (for example a card the app writes that makes a machine behave unsafely, or a way for a malicious card to crash the app), please report it privately with GitHub's "Report a vulnerability" button on this repository's Security tab rather than in a public issue. We will reply there.
